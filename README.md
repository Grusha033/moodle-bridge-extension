# Moodle Agent Bridge (Extension)

Расширение для Chrome / Edge / Brave с общей облачной базой ответов для Moodle.

## Установка (1 минута)

1. Скачайте репозиторий: **Code -> Download ZIP** и распакуйте в любую папку (или `git clone https://github.com/Grusha033/moodle-bridge-extension.git`).
2. Откройте `chrome://extensions/` -> включите **Режим разработчика** -> **Загрузить распакованное расширение** -> выберите эту папку.
3. Всё готово — сервер уже подключён по умолчанию, логиниться не нужно.

## Автообновление

- Расширение само проверяет новые версии в этом репозитории и показывает бейдж **`UPD`** на иконке, когда вышло обновление.
- Чтобы обновиться в 1 клик: запустите **`update.bat`** (Windows) или **`./update.sh`** (Linux/macOS), затем нажмите кнопку обновления в `chrome://extensions/`.
